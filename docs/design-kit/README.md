# joeyoosenbrug.nl design kit

The design kit has moved. It used to live here and was copied into every app by hand; it is now an npm package with its own repository and documentation.

- **Package:** [`@joeykwispel/design-kit`](https://www.npmjs.com/package/@joeykwispel/design-kit)
- **Documentation:** [designkit.joeyoosenbrug.nl](https://designkit.joeyoosenbrug.nl)
- **Source:** [github.com/joeykwispel/designkit](https://github.com/joeykwispel/designkit)

```sh
npm i @joeykwispel/design-kit @fontsource-variable/inter @fontsource-variable/jetbrains-mono
```

Change the design there, not here. The copies that were in this folder (`jo-kit.css`, `jo-header.css`, `jo-header.js`, `JoHeader.tsx`, `jo-header.component.ts`, `header.html`, `demo.html`) are in the git history.
